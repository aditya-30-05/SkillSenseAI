The **SkillSense AI Frontend** is the mission-control trainer cockpit application built with **Flutter** and **Dart**. It provides real-time HUD telemetry, hazard radar visualization, interactive timeline replay, and trainee evaluation dashboards across Web, Desktop (Windows, macOS, Linux), and Mobile (Android, iOS).

## 🚀 Running the App

```bash
# Get dependencies
flutter pub get

# Run on Chrome
flutter run -d chrome

# Run natively on Windows Desktop
flutter run -d windows
```
