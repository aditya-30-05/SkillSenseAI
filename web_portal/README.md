The **SkillSense AI Web Portal** is the centralized administrative and curriculum operations dashboard built with **Next.js 16**, **React 19**, and **shadcn/ui**. It complements the primary Flutter Cockpit application by providing cohort administration, curriculum management, safety compliance audits, and analytics reporting.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the portal.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🛠️ Tech Stack & Dependencies
* **Framework:** Next.js 16 (App Router)
* **Library:** React 19
* **Styling:** Tailwind CSS with Radix UI Primitives & shadcn/ui
* **Icons:** Lucide React
